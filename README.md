## CRM de Atendimento ao Cliente (n8n)

Este repositório também contém um **CRM de atendimento ao cliente com automações n8n** e
design moderno/profissional.

➡️ Ver documentação e instruções de execução em **[`crm/README.md`](crm/README.md)**.

### Executar rapidamente

```bash
cd crm
npm run dev
# → http://localhost:4000
```

Ou com Docker (CRM + n8n + Postgres):

```bash
cd crm
docker compose up -d --build
# CRM: http://localhost:4000 · n8n: http://localhost:5678
```
